
== Definición de requerimientos

=== Planteamiento del problema (Aprox 450 palabras)

Actualmente la cadena tiene una solución distinta por sucursal, este acercamiento provoca *inconsistencias, errores y dificulta tener un control centralizado*. El proyecto busca reemplazar esa solución por una que sea *centralizada* y con soporte al *crecimiento constante* el cuál deberá tener un rendimiento optimizado. Deberá soportar operaciones diarias en más de *5,000 operacciones y 1,000,000* de habitaciones. Con una solución generalizada se podrían implementar precios dinámicos y políticas de ocupacíon avanzadas, incrementando los ingresos y mejorando la satisfacción del cliente.

==== CU03 - Reservar estancia
*ID:* CU03

*Nombre:* Reservar una habitación

*Descripción:* El Huésped reserva una habitación para hospedarse

*Actor(es):* Huésped

*Disparador:* Huésped selecciona “Reservar” en el MenuPrincipalHuésped
Precondiciones: N/A

*Flujo Normal*

1.	El Sistema recupera de la base de datos las habitaciones y sus fechas disponibles (Ver EX01)
2.	El Sistema abre ReservaHabitacionesHuésped mostrando los datos recuperados
3.	El Huésped selecciona una habitación y la fecha que desea reservar
4.	El Huésped reserva la habitación (ver FA01)
5.	El Sistema abre PáginaPago solicitando los datos de pago del Huésped
6.	El Huésped ingresa sus datos de pago y selecciona “Pagar”
7.	El Sistema envía los datos al Sistema de cobros (Ver EX02)
8.	El Sistema envía al Huésped su comprobante de pago y de reservación
9.	El Sistema cierra ReservaHabitacionesHuésped
10.	Termina el caso de uso

*Flujos alternos*

*Excepciones*

*EX01 – Error al conectarse a la base de datos*

*EX02 – Error al procesar el pago*

*Postcondiciones:* El Huésped reservó una habitación y se guardó en la base de datos

*Reglas de negocio:* N/A

*Incluye:* N/A

*Extiende:* N/A
