
== Impulsores arquitectónicos

=== Atributos de Calidad Principales

A partir de los intereses pricipales de los interesados y la funcionalidad principal requerida del sistema, los siguientes atributos de calidad han sido determinados como los más importantes. A continuación se presentan las definiciones de atributos de calidad que serán tomadas como referencia para el proyecto. 

*Seguridad* +
Capacacidad de protección de la información y los datos de forma que personas o sistemas tengan el grado de acceso a los datos adecuado para sus tipos y niveles de autorización, y para defenderse de los patrones de ataque de agentes malintencionados. +
- _ISO/IEC 25010_

*Disponibilidad* +
Propiedad del software para estar disponible y listo para realizar su tarea cuando se necesita, la capacidad para recuperarse tras una falla, y la capacidad del sistema para arreglar o enmascarar los defectos de tal forma aque no se manifiesten como una falla. +
- _(Parafrasis) Software Architecture in Practice, L. Bass, P. Clements R. Kazman_

*Rendimiento*
Grado en el que un producto realiza sus funciones dentro de parámetros de tiempo y rendimiento especificados y hace uso eficiente de los recursos bajo condiciones especificas. +
- _ISO/IEC 25010_

*Usabilidad* +
Grado en el que un sistema, producto o servicio puede ser usado por usuarios especificos para conseguir objetivos especificos con eficacia, eficiencia y satisfacción en un contexto de uso especificado. -_ISO 9241-11:2018_

== Escenarios de atributos de calidad

=== Seguridad

==== Confidencialidad

==== Fuente
Un adversario externo a la organización.

==== Estímulo
Intenta capturar los datos de pago de un cliente con un ataque Man-in-the-Middle

==== Artefacto
Sistema de pagos

==== Entorno
El sistema esta en linea

==== Respuesta
- El sistema cancela la transacción.
- El sistema bloquea la conexión sospechosa

==== Medida
El sistema detecta y detiene estos ataques en el 99% de los casos.

==== Integridad

==== Fuente
Un empleado dentro de la empresa.

==== Estímulo
Realiza un cargo falso a la estancia de un cliente.

==== Artefacto
Portal de recepción.

==== Entorno
Conectado de la red de la cadena.

==== Respuesta
- El sistema registra que empleado realizo el cargo.
- El sistema restaura el balance real.

==== Medida
30 segundos después de recibir un reporte.

=== Disponibilidad

==== Recuperación de fallas

==== Fuente
El servicio de consulta de disponibilidad.

==== Estímulo
Registra un aumento inesperado y sostenido en el número de solicitudes que expiran.

==== Artefacto
El servicio de consulta de disponibilidad.

==== Entorno
Operación normal.

==== Respuesta
El sistema aumenta el máximo de solicitudes que pueden ser atendidas a costa de la velocidad de respuesta individual.

==== Medida
El sistema entra y sale del modo degradado respectivamente en menos de 5 minutos tras regresar a carga habitual.

==== Detección de fallas

==== Fuente
El interfaz del proveedor bancario.

==== Estímulo
Pasa más de 30 segunoods sin responder las solicitudes de pago.

==== Artefacto
El servicio de reservación.

==== Entorno
Operación normal.

==== Respuesta
El sistema cancela las transacciones en curso, desactiva el servicio de reservación, notifica al portal de clientes y a la administración de la cadena..

==== Medida
El servicio de reservación vuelve a estar habilitado en menos de 60 segundos tras restablecerse la comunicación con el proveedor.

=== Rendimiento

==== Tiempo de Respuesta

==== Fuente
Un huésped

==== Estímulo
Hace una búsqueda de alojamiento durante temporada alta.

==== Artefacto
En el portal de clientes.

==== Entorno
El sistema está bajo carga máxima.

==== Respuesta
El sistema devuelve con los resultados de la búsqueda.

==== Medida
En 2 segundos o menos para el 95% de las peticiones.

=== Rendimiento

==== Capacidad de procesamiento

==== Fuente
Multiples huespedes

==== Estímulo
Confirmación su reservación durante temporada altaa.

==== Artefacto
En el portal de clientes.

==== Entorno
El sistema está bajo carga máxima.

==== Respuesta
El sistema confirma la reservación.

==== Medida
En 2.5 segundos o menos para el 95% de las peticiones durante picos de 3 transacciones por segundo.

=== Usabilidad

==== Capacidad de aprendizaje

==== Fuente
Recpecionista

==== Estímulo
Necesita aprender las tareas de check-in y check-out.

==== Artefacto
En el portal de clientes.

==== Entorno
En tiempo de ejecución.

==== Respuesta
El sistema guia al usuario con navegación intuitiva y mensajes informativos.

==== Medida
Más del 90% de los recepcionistas novatos pueden completar el check-in y el check-out exitosamente con 10 minutos de instrucción por tarea.

==== Confianza y satisfacción

==== Fuente
Huésped

==== Estímulo
Intenta realizar su primera reservación

==== Artefacto
En el portal de clientes.

==== Entorno
En tiempo de ejecución.

==== Respuesta
El sistema guia al usuario con navegación intuitiva a través del flujo de reservación con menos de 5 pasos.

==== Medida
El 80% de los nuevos usuarios reportan que el sistema es agradable de usar en la encuesta de satisfacción.
