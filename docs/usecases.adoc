=== Descripciones de caso de uso

*CU01 - Buscar hotel* +
*ID:* CU01 +
*Nombre:* Buscar hotel +
*Descripción:* Este caso permite que el _Huésped_ busque *Hoteles* mediante la función de búsqueda de *Hoteles* por ciudad. 
El resultado es que el _Huésped_ pudo ver los hoteles de la ciudad que consultó. +
*Actor(es):* Huésped +
*Disparador:* _Huésped_ selecciona "Buscar hotel” +
*Precondiciones:* N/A

*Flujo Normal* +
1. El _Sistema_ recupera de la base de datos las ciudades disponibles (ver EX01) +
2. El _Huésped_ selecciona una ciudad +
3. El _Sistema_ recupera de la base de datos los hoteles de esa ciudad (ver EX01)
4. El _Sistema_ muestra los hoteles recuperados (ver FA01) +
5. El _Huésped_ puede consultar la disponibilidad de habitaciones (Extiende CU02) +
6. Termina el caso de uso

*Flujos alternos* +

*FA01 - Buscar otro hotel* +
1. El _Huésped_ busca en otra ciudad +
2. Regresa al flujo normal 3

*Excepciones* +

*EX01 – Error al conectarse a la base de datos* +
1. El _Sistema_ informa al _Huésped_ que hubo un error al conectarse a la base de datos +
2. Termina el caso de uso

*Postcondiciones:*
POST01: Se consultaron *Hoteles* en la base de datos +
POST02: El _Huésped_ recibió los datos de un hotel +
*Reglas de negocio:* N/A +
*Incluye:* N/A +
*Extiende:* CU02

*CU02 - Consultar disponibilidad de habitaciones* +
*ID:* CU02 +
*Nombre:* Consultar disponibilidad de habitaciones +
*Descripción:* Este caso permite que el _Huésped_ consulte la disponibilidad de *Habitaciones* mediante un filtro de *Check-in*, *Check-out* y cantidad de *Huéspedes*.
 El resultado es que el _Huésped_ pudo ver la disponibilidad de *Habitaciones* con las características que solicitó. +
*Actor(es):* Huésped +
*Disparador:* Húesped selecciona "Consultar disponibilidad" +
*Precondiciones:* Haber consultado un hotel antes

*Flujo Normal* +
1. El _Huésped_ selecciona una fecha de *Check-in*, *Check-out* y cantidad de huéspedes y selecciona "Buscar" +
2. El _Sistema_ recupera de la base de datos las *Habitaciones* disponibles con ese filtro (ver EX01) +
3. El _Sistema_ muestra las *Habitaciones* recuperadas +
4. El _Huésped_ puede reservar una estancia (extiende CU03) +
5. Termina el caso de uso

*Flujos alternos*

*FA01 - Cambiar características* +

2. Regresa al flujo normal 2

*Excepciones*

*EX01 – Error al conectarse a la base de datos* +
1. El _Sistema_ informa al _Huésped_ que hubo un error al conectarse a la base de datos +
2. Termina el caso de uso

*Postcondiciones:* +
POST01: Se consultaron *Habitaciones* en la base de datos +
POST02: El _Huésped_ pudo ver la disponibilidad de las habitaciones con las características seleccionadas +

*Incluye:* N/A +

*CU03 - Reservar estancia* +
*ID:* CU03 +
*Nombre:* Reservar una habitación +
*Descripción:* Este caso permite que el _Huésped_ realice reservar una *Reseravción* mediante su interacción con la página web. El resultado es una *Reservación* del _Huésped_. +
*Actor(es):* Huésped +
*Disparador:* Huésped selecciona “Reservar” +
*Precondiciones:* Haber buscado un hotel o consultado la disponibilidad de una habitación

*Flujo Normal* +
1. El _Sistema_ recupera los datos de la *Habitación* solicitada (ver EX01) +
2. El _Sistema_ muestra los datos de la *Habitación* recuperada +
3. El _Huésped_ selecciona "Reservar Habitación" (ver FA01) +
4. El _Sistema_ solicita los datos de pago al _Huésped_ (ver FA02) +
5. El _Huésped_ ingresa sus datos de pago y selecciona “Pagar” +
6. El _Sistema_ envía los datos al Sistema de cobros (Ver EX02) +
7. El _Sistema_ envía al _Huésped_ su comprobante de pago y de reservación +
8. El _Sistema_ registra en la base de datos la *Reservación* (ver EX01) +
7. Termina el caso de uso

*Flujos alternos*

*FA01 - Cancelar* +
1. El _Huésped_ selecciona "Cancelar"
2. Termina el caso de uso

*FA02 - Iniciar sesión*
1. Si el _Huésped_ no ha iniciado sesión debe iniciar sesión con sus credenciales. +
2. Regresa al flujo normal 3.

*Excepciones*

*EX01 – Error al conectarse a la base de datos* +
1. El _Sistema_ informa al _Huésped_ que hubo un error al conectarse a la base de datos +
2. Termina el caso de uso

*EX02 – Error al procesar el pago*
1. El _Sistema_ informa al _Huésped_ que hubo un error al realizar el cobro +
2. Termina el caso de uso

*Postcondiciones:* +
POST01: Se registró en la base de datos la *Reservación* hecha +
POST02: Se envió un comprobante de *Reservación* al _Huésped_ +
POST02: Se actualiza en la base de datos la disponibilidad de la *Habitación* +

*Reglas de negocio:* N/A +
*Incluye:* N/A +
*Extiende:* N/A
